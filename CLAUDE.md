# ElefantBlasterCommon

Static lib shared by ElefantBlasterServer and ElefantBlasterServerInterface (the Client does not link it yet). Mentor mode: see workspace `CLAUDE.md`.

codebase-memory project: `K-git-ElefantBlaster-ElefantBlasterCommon`. Ignore `tools/protoc/` (prebuilt protoc binaries + google protos).

## Contents (include root = `src/`, so `#include <entities/user.hpp>`)

- `proto_files/admin/*.proto` — admin protocol (proto3). `protocol.proto` is the envelope: `protocol.ClientMessage` / `protocol.ServerMessage`, each a `oneof body`. Field-number blocks by domain: 1–13 server control, 101+ auth, 201+ users, 211+ groups, 221+ roles, 231+ permissions; responses come in `*SuccessResponse` / `*FailureResponse` pairs.
- `src/network/shared/admin_protocols/` — **generated** `.pb.h/.pb.cc` (gitignored; never edit). Regenerated by `proto_scripts/proto_generate.py`, which CMake runs at **configure time**; it hashes inputs into `proto_files/admin/.cache.json` and only re-runs protoc on change. Groups/outputs are configured in `proto_scripts/proto_configs.json`.
- `src/network/shared/msg_header.hpp`, `msg_manager.hpp` — custom binary framing (8-byte header: magic `0xFF6E`, protocol version, size, head, sub; then body) + a cursor-style parser over a receive buffer. Intended for the game protocol; the admin channel uses protobuf over WebSocket instead.
- `src/entities/` — plain structs shared over the wire / DB: `User` (+`UserType`), `Group`, `Role`, `Permission` (+`RiskLevel`), `system_groups/roles` (built-in defaults).
- `src/entities/permission_name.hpp` — permission names as `inline constexpr std::string_view` in nested namespaces (`permission::user::view` = `"user.view"`, `"*.all"` = `"user.*"`).
- `src/entities/permission_list.hpp` — `kPermissions`: the master `constexpr std::array<DefPermission>` (risk level, name, description) used to seed the DB.
- `src/storage/shared/db_definitions.hpp` — enums shared by DB queries and UI (`SortBy`).

## Workflow notes

- Adding a protocol message: edit the `.proto`, add it to the `oneof` in `protocol.proto` with a number in the right block, re-run CMake configure (or `run_scripts.sh`), then handle the new `body_case()` on both Server (`AdminServer::OnMessage`) and ServerInterface (`AdminClient::OnMessage`).
- Adding a permission: add the name to `permission_name.hpp` **and** an entry to `kPermissions`; the server seeds permissions from that list.
- Links `protobuf::libprotobuf` PUBLIC (consumers get protobuf transitively) and `aries_base` PRIVATE.
